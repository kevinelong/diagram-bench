# Work packages, 2026-10-21

Five packages, one per worktree, each owning **disjoint files** so merges are mechanical. Integration is mine:
I review each diff, run the acceptance, and merge in dependency order.

## The boundary every package inherits

- **No model runs, no GPU, no network.** Everything here is code and instrumentation. The lab's
  one-inference-workload rule survives the delegation: any generation, rendering against a model, or timing run
  stays serial with me.
- **No new dependencies** unless already in `.venv`.
- **Acceptance is a self-test**, not a demo: each package ships fixtures with known-good and known-bad inputs and
  asserts the expected verdicts, so a later edit that breaks a detector fails loudly.
- **Commit on your branch**, one commit per package, message naming what changed and why.
- **Do not touch files you do not own.** If something else must change, note it in the commit message instead.
