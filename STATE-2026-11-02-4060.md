## Fixed on the way in

`zimage_ui.py:6977` — `_share_gallery` was a `@staticmethod` that called `self._column_caps()`, so **every gallery-boundary
drag died with `NameError: name 'self' is not defined`** and `test_sizing.py` stopped after 27 passes. One bound call site;
dropping the decorator was the fix (`6eddba7`, now on `master`).

- **Machine facts**: i9-13950HX 24C/32T 2.2 GHz, 15.7 GB, Windows 11 Home Insider build 26340, RTX 4060 8,188 MiB

- **CPU reference figures** (cited, with sample counts): GB6 2,907 / 16,049 (n=907); PassMark 40,286 (single 3,833, n=1,858);
  Cinebench 2024 127 / 1,901; Blender 332. DDR5-5600 dual channel = 89.6 GB/s, 0.88x the desktop's bandwidth.

- **The cliff**: a 1,002-picture worst folder cost `folder_click_to_pane` **11,718 ms p50 / 44,060 ms p90** — 41x the
  540-picture cost, for twice the pictures.
